# NOBU16 DLC 북 이미지 추출기

추출 경로를 화면에서 지정하는 네이티브 Windows GUI 도구입니다. C++로 작성했습니다.

## 다운로드

[GitHub Releases](https://github.com/parsifal295/nobu16-dlc-book-extractor/releases/latest)에서 최신 `Nobu16DlcBookExtractor.exe`를 내려받으세요. 설치 과정 없이 EXE 하나만 실행하면 됩니다.

공개 코드 서명 인증서로 서명된 프로그램이 아니므로 Windows SmartScreen 경고가 표시될 수 있습니다. 파일의 무결성은 릴리스에 포함된 `SHA256SUMS.txt`로 확인할 수 있습니다.

## 실행

[Nobu16DlcBookExtractor.exe](Nobu16DlcBookExtractor.exe)를 실행한 뒤 다음 순서로 사용합니다.

1. `게임 설치 폴더`에서 `NOBU16PK.exe`가 있는 폴더를 선택합니다.
2. `출력 폴더`를 선택합니다.
3. 필요하면 `기존 PNG 덮어쓰기`를 선택합니다.
4. `추출 시작`을 누릅니다.

진행률과 현재 저장 중인 파일이 화면에 표시됩니다. 완료 후 `출력 폴더 열기`를 누르면 결과를 바로 확인할 수 있습니다.

## 출력 결과

총 109장을 원본 수록 순서대로 추출합니다. 투명 여백은 자동으로 제거하고 펼침면은 분할하지 않습니다.

```text
선택한 출력 폴더\
├─ 무장 아트북\
│  ├─ 1.png
│  └─ ... 29.png
├─ 40주년 메모리얼북\
│  ├─ 1.png
│  └─ ... 23.png
└─ 시부사와 코우 비전 공략 데이터 & 무장 아트북\
   ├─ 1.png
   └─ ... 57.png
```

원본 보호를 위해 게임 설치 폴더 내부는 출력 위치로 사용할 수 없습니다. 같은 이름의 PNG가 있으면 기본적으로 중단하며, `기존 PNG 덮어쓰기`를 선택한 경우에만 교체합니다. 게임의 `.n16` 파일은 읽기만 하며 변경하지 않습니다.

## 소스 빌드

MinGW-w64 UCRT의 C++17 컴파일러가 설치된 환경에서 `build_native.cmd`를 실행합니다. 정적 링크된 `Nobu16DlcBookExtractor.exe`가 생성되며 별도의 MinGW DLL은 필요하지 않습니다.
